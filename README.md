# Hvilken arkitektur har I valgt, og hvorfor? 
  MVC: Fordi den er vi bekendt med og ved hvordan nogenlunde fungere. i forhold til at adskille ansvar og gøre det nemt at gå ind og kigge/ændre i ting.

# Hvad ville I ændre, hvis applikationen skulle anvendes af mange brugere? 
  Håndtere race condition. 

# Hvilke fejl fandt I under udvikling og test?
  Nogen validerings fejl i forhold til at hvis der blev søgt efter Id som ikke var der., og glemte at indsætte return keyword nogen steder samt at ekspotere functioner eller moduler.
  

# Hvilken forbedring gennemførte I efter kode-review? 
  Ansvars opdeling, blev mere klart og samt hvad den forskellige moduler enlig håndteret.
